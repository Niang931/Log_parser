Pipeline Architecture
📥
1 · Multi-format Loader
XML, JSON, CSV, TSV, YAML, INI, syslog, plain text. Auto-detects format. Key-value table detection. Strips syslog prefixes.
6 loaders
↓
🛡
2 · Normalise + Guardrails
Dedup, length cap, prompt-injection detection. Blocked: "ignore instructions", "DAN mode", system prompt injection.
injection awareness
↓
🤖
3 · LLM Mask Synthesis
Domain schema injected as grounding context. Self-consistency voting × 3 temperature-varied completions. LLM called once per run not per line.
RAG-lite grounding
↓
🔄
4 · Adaptive Feedback Loop
Probes parse-rate. Below threshold → re-synthesise on unparsed lines. Up to 3 rounds. Stops early when met.
adaptive parsing
↓
🌳
5 · Drain Clustering
Pre-masking before clustering. Named tokens not wildcards. Adaptive sim-threshold. Cluster stability scoring.
original architecture
↓
✅
6 · JSON-Schema Validation
Every record validated against OUTPUT_SCHEMA. Failures → quarantine table. Health check asserts fail fast.
guardrails + validators
Design Rationale
Why Drain + LLM?
ApproachStrengthWeakness
Regex onlyFastCan't generalise
LLM per lineFlexibleExpensive at scale
Drain + LLM masksGeneralises, O(1) costNeeds sample
LLM synthesises masks once; Drain applies them at O(n). 500 lines = 1–4 LLM calls.
Reproducibility
• Global seed controls all RNG
• Deterministic run_id per file + seed
• Drain state serialised for warm-start
• Template fingerprint (SHA-256) cross-run verify
• Mask cache reused on identical file stems
Security
• Prompt-injection blocklist on every line
• File extension allowlist (.log .csv .xml etc)
• 50 MB upload cap, max 20 files per batch
• API keys via .env — never in source
• Docker: non-root uid 10001, read-only mount
Cost / Latency
• Groq free: 14,400 req/day, fastest inference
• Gemini Flash free: 1,500 req/day
• Batch files staggered 0.5s apart (no LLM overload)
• Mask cache reused across same-format files
• Adaptive loop stops early — never over-calls

Batch upload example
curl -X POST http://localhost:8000/api/parse-batch \
  -F "files=@fab1.log" \
  -F "files=@recipes.xml" \
  -F "files=@constants.csv" \
  -F "llm_provider=groq"

  "queued": 3,

    {"run_id": "run_recipes_...", "stream": "/api/stream/..."},
    {"run_id": "run_constants_...", "stream": "/api/stream/..."}
  ]
}
Stream all batch runs
const resp = await fetch('/api/parse-batch', {
  method: 'POST', body: formData
});
const {runs} = await resp.json();

// Subscribe to each run's SSE stream
runs.forEach(run => {
  const es = new EventSource(run.stream);
  es.onmessage = e => {
    const ev = JSON.parse(e.data);
    if (ev.type === 'done') {
      updateFileCard(run.run_id, ev);
      es.close();
    }
  };
});
